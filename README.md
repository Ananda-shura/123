# Дополнение к Zapret 1.10.4 для проверки на Windows 11

[Скачать ZIP дополнения](https://github.com/Ananda-shura/123/raw/refs/heads/zapret-audit-1.10.4/zapret-1.10.4-optimized.zip)

Это **дополнение без EXE/DLL/SYS**, а не полный дистрибутив Zapret. Используйте его с неизменённым официальным релизом 1.10.4. Исходные файлы не заменяются. Профиль предназначен только для YouTube; работу Discord он не обеспечивает.

1. Сохраните исходный ZIP как резервную копию и распакуйте его в новую папку.
2. Распакуйте дополнение в эту папку: `start-youtube.cmd` должен оказаться рядом с `service.bat`.
3. Прочитайте [инструкцию](zapret-files/README-INSTALL.md), выполните диагностику и остановите прежний экземпляр перед новым запуском.
4. Проверьте YouTube, Steam и CS2 на своей Windows. Работоспособность на компьютере пользователя ещё не подтверждена.

Проверки Linux: исходные 59 файлов совпали с официальным релизом, синтаксис PowerShell и формирование аргументов проверены. Пустой hostlist, изменённый бинарный файл и отсутствующий QUIC-шаблон блокируют запуск. Windows EXE и драйвер в облаке не запускались. Постоянная служба/автозапуск не создавались.
