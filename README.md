# Готовая папка Zapret 1.10.4

## Скачать и запустить

**[Скачать полную готовую папку — ZIP, около 13 МБ](https://github.com/Ananda-shura/123/raw/refs/heads/zapret-audit-1.10.4/zapret-1.10.4-ready-full.zip)**

1. Распакуйте ВЕСЬ архив в новую папку, например `C:\Zapret-ready`.
2. Откройте распакованную папку `Zapret-1.10.4-ready` и дважды нажмите **START.cmd**.
3. В запросе Windows на права администратора нажмите «Да». Оставьте окно открытым.

Исходный релиз, DLL, драйвер и списки уже внутри. Ничего объединять, дописывать или отдельно скачивать не нужно. Если старая копия Zapret уже работает, новый запуск сообщит об этом и остановится; он не удаляет службы и не завершает чужие процессы. Выключите свою старую копию и повторите запуск. Для остановки нового профиля закройте его окно или нажмите Ctrl+C.

Это отдельный профиль **только для YouTube**: он не обеспечивает обход Discord. Все 59 оригинальных файлов релиза сохранены неизменными; бинарники проверены по официальному ZIP. Запуск проверяет SHA-256, список доменов и конфликтующие процессы, запрашивает UAC и не создаёт постоянный автозапуск. Глобальные политики PowerShell, DNS, Defender и брандмауэр не меняются. WinDivert при работе может зарегистрировать/запустить собственный драйвер, как в оригинале.

**Работа на вашей Windows и у провайдера ещё требует проверки.** Здесь проверены синтаксис и безопасные ветви построения аргументов/контроля файлов; Windows EXE, драйвер, UAC и воспроизведение видео в Linux не выполнялись.

## Если YouTube не открывается

[Скачать небольшую диагностику](https://github.com/Ananda-shura/123/raw/refs/heads/zapret-audit-1.10.4/youtube-diagnostic.zip). Оставьте START.cmd работающим, распакуйте диагностику в любую новую папку и нажмите DIAGNOSE.cmd. Через 1–2 минуты откроется YOUTUBE-DIAGNOSTIC-....txt с DNS/HTTPS-результатами.

Диагностика не меняет настройки Windows, DNS и службы. Ответы DoH используются только для одного временного curl-запроса. Результаты нужны, чтобы отделить DNS, TLS и браузерный отказ; они не доказывают воспроизведение видео. [Исходник и проверки](diagnostic/VALIDATION.md).
