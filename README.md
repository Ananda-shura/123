# Zapret 1.10.4: проверка и подбор профиля YouTube

**[Скачать полную папку с подбором — ZIP, около 13 МБ](https://github.com/Ananda-shura/123/raw/refs/heads/zapret-audit-1.10.4/zapret-1.10.4-auto-test.zip)**

1. Закройте прежнее окно START.cmd. Старую папку сохраните.
2. Распакуйте новый архив в отдельную папку.
3. Откройте `Zapret-1.10.4-auto`, нажмите **START.cmd** и подтвердите запрос Windows.
4. Подождите 1–3 минуты. Если показано «HTTPS-проверка пройдена», оставьте окно открытым, полностью перезапустите браузер и проверьте YouTube.
5. Если ни один вариант не подошёл, откроется `RESULT.txt`; он также сохранится в `logs/autopick-...`. Этот отчёт нужен для следующего шага диагностики.

Новый запуск проверяет прямой TCP и HTTPS без фильтра, затем при необходимости сравнивает четыре штатных TLS-стратегии релиза. Победитель должен дать HTTP200 с телом страницы на одном и том же IP сравнения и через обычный DNS. Если страница отвечает без Zapret, новый фильтр не запускается и выводится соответствующее сообщение. Это проверка HTTPS-страницы, не гарантия видео, QUIC или работы браузера.

Профили ограничены YouTube и TCP/UDP443, без Game Filter/IPSet и timestamp-fooling. DNS, службы, Happ/VPN, Defender, брандмауэр и глобальные политики не меняются. Другие процессы/службы не останавливаются. Для собственных тестовых процессов применяется Windows Job Object; ошибка назначения Job прерывает подбор. Все 59 оригинальных файлов сохранены, бинарники проверяются по хэшам. Исходники зависимостей и лицензии включены в архив.

На конкретном провайдере работа четырёх вариантов заранее не подтверждена. Реальные Windows UAC/Job/WinDivert, браузер и игровые показатели остаются проверкой на целевом компьютере. Код и фикстуры проверены в Linux; результаты не выдаются за Windows-интеграционные испытания.
