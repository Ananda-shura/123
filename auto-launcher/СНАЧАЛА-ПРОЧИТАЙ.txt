ПРОФИЛЬ YOUTUBE С ПРОВЕРКОЙ И ПОДБОРОМ

1. Закройте окно прежнего START.cmd. Не удаляйте старую папку.
2. Распакуйте ВЕСЬ этот архив в новую папку.
3. Откройте Zapret-1.10.4-auto, дважды нажмите START.cmd и подтвердите «Да» в запросе Windows.
4. Подождите примерно 1–3 минуты. Сначала проверяется прямой TCP и HTTPS без обходчика.
   Затем при необходимости проверяются четыре штатных варианта Google TCP из релиза 1.10.4.
5. Если появился зелёный текст «HTTPS-проверка пройдена», оставьте окно открытым,
   полностью перезапустите браузер и проверьте YouTube. Успешный HTTP-тест не гарантирует видео.
6. Если написано, что без Zapret сайт отвечает HTTP 200, фильтр не запускается: проверьте
   браузер и сообщите результат. Это проверка страницы, а не доказательство доступности видео.
7. Если ни один вариант не подошёл, откроется RESULT.txt. Пришлите его в чат.

Старые процессы и службы автоматически не останавливаются. Если другая копия работает,
будет показано сообщение. Закройте своё старое окно и повторите запуск.
Happ, VPN, DNS, брандмауэр, Defender и глобальные политики Windows этот запуск не меняет.
Постоянная служба Zapret и автозапуск не создаются.

Программа запускает и останавливает только собственные временные процессы winws.
Тестовые процессы помещаются в Windows Job Object: после закрытия окна их дескриптор
закрывается, и ОС завершает связанные процессы. Чужие процессы в Job не добавляются.
WinDivert при работе может запустить собственный драйвер, как в исходном релизе.
Если Job Object не удаётся настроить, подбор прерывается, собственный процесс завершается.

Тесты используют временный --resolve только для одного curl-запроса; системный DNS не меняется.
Победитель должен ответить HTTP 200 и передать минимум 1024 байта как через фиксированный
адрес сравнения, так и через обычный DNS. Проверка сертификата TLS сохраняется.
Отдельно требуется проверить видео, QUIC, Steam и CS2 на вашем компьютере.

Откат: закройте это окно и вернитесь к сохранённой старой папке.
При ошибке результат находится в logs/autopick-.../RESULT.txt. Полные stdout/stderr лежат
рядом только для локального разбора; они могут содержать путь установки. Для отправки
используйте RESULT.txt, в котором путь профиля пользователя не сохраняется.

Все исходные 59 файлов релиза и 27 компонентов bin сохранены неизменными.
START.cmd выполняет открытый сценарий autopick/autopick.ps1 после проверки его SHA-256.
Сценарий загружается как текст PowerShell-команды; ExecutionPolicy не изменяется.
Корпоративные ограничения и защиту Windows пакет не отключает.
Реальный запуск WinDivert/UAC/Job Object на вашей Windows здесь не проверялся.
