# Проверка диагностического инструмента

- Проверены синтаксис исходника и команды DIAGNOSE после разворачивания экранирования процентов CMD, ASCII/CRLF и ограничение Windows CMD 8191 символ.
- Точная встроенная PowerShell-команда DIAGNOSE выполнена в Linux с подставными Windows-запросами и безопасной тестовой программой вместо curl.exe.
- Проверены 7 HTTPS-записей, 2 DoH-провайдера, условный --resolve, сохранение кодов ошибок curl и отчёта, редактирование URL с userinfo, Unicode/пробелы/спецсимволы пути.
- Повторный запуск не перезаписывает предыдущий отчёт.
- Симуляция не подтверждает сетевую доступность YouTube, реальное поведение Windows curl/CIM/UAC и не заменяет запуск на компьютере пользователя.
- Реальные запросы с компьютера пользователя ещё не выполнялись. DNS/службы/сетевые политики этим инструментом не изменяются.
