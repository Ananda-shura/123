# Причина и итоговое изменение

Предыдущий запуск подтвердил страницу YouTube (FAKE-TLS-AUTO-ALT), Telegram Web
(BASE-MULTISPLIT), официальный список из 14 сетей и сохранение контрольных ответов ya.ru/Steam.
Пользователь затем подтвердил региональную ошибку ChatGPT и зависание Telegram Desktop.
При закрытом START.cmd и включённом существующем Happ оба сервиса заработали.

Новая папка использует прежний YouTube-only START.cmd/autopick без изменения файлов.
Она не применяет дополнительные DPI-профили ChatGPT/Telegram из expanded-варианта.
SETUP-HAPP.cmd проверяет хэши своих исходников и создаёт отдельный профиль маршрутизации Happ.
Профиль соответствует полному набору полей официального генератора; DNS внутри Happ задан явно.
Только domain: правила перечисленных сервисов и прошедшие строгую проверку Telegram CIDR
попадают в прокси. GlobalProxy — строка "false", остальные адреса по правилам идут напрямую.
Ни сторонний сервер, ни подписка, ни непроверенные прокси не добавлены.

Официальный CIDR endpoint загружается на компьютере пользователя через его рабочее подключение.
При ошибке HTTPS/пустом/HTML/локальном/широком/повреждённом списке импорт не выполняется.
Результат сохраняется в уникальной папке; старые файлы и профили скрипт не удаляет.
URI routing/add открывается в Happ. Интеграционная проверка импорта/выбора профиля,
TUN/sniffing/DNS и совместной работы с WinDivert остаётся проверкой на Windows.
Сценарии URL/JSON/правил с тестовыми данными не считаются реальной проверкой маршрутизации.

Источники схемы и семантики закреплены в HAPP-SOURCE-PROVENANCE.json.
Содержимое пользовательского RESULT.txt и настройки его сервера не публикуются.
