# Полная папка для запуска

Эта версия включает все 59 неизменённых файлов исходного ZIP 1.10.4. Их SHA-256
сверены с официальным архивом. Старый архив дополнений остаётся доступен отдельно.
Новое: START.cmd, ready-messages.json, отдельный hostlist YouTube, краткая инструкция,
ORIGINAL-SHA256.json и материалы проверки. START.cmd запрашивает UAC при необходимости.
Бинарники, драйвер и стратегии оригинала не изменялись. Основной профиль остаётся тем же:
YouTube TLS multisplit и QUIC fake6, только TCP/UDP443, без Game/IPSet.

Глобальные политики исполнения PowerShell не изменяются, -ExecutionPolicy Bypass не используется.
Открытая команда встроена в CMD; проверяемая копия находится в launcher-source.ps1.
Она читает JSON только как данные, проверяет bin и hostlist и отказывается запускать второй
обходчик. Никакие новые файлы не загружаются при старте.

Аудит и таблица стратегий относятся к исходному релизу и исходному профилю из предыдущего
дополнения. Для установки полной папки используйте СНАЧАЛА-ПРОЧИТАЙ.txt в корне:
предыдущие инструкции о совмещении двух ZIP здесь не нужны.

Функциональная проверка на Windows и у провайдера ещё не выполнена. Наличие исходников и
совпадение официальных хэшей не заменяют проверку цифровой подписи драйвера на Windows.
