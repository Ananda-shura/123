# Исходные тексты включённых библиотек

`cygwin-3.4.10-source.tar.gz` содержит полное дерево официального тега Cygwin 3.4.10,
включая newlib, winsup и сценарии сборки. Лицензия DLL — LGPLv3+ с дополнительным
разрешением на линковку; отдельные компоненты используют другие лицензии,
которые сохранены в исходных файлах и в папке licenses/Cygwin.

`WinDivert-2.2.2-source.tar.gz` содержит полное дерево официального тега WinDivert v2.2.2,
включая исходники драйвера и сценарии сборки MSVC/WDK/MinGW. Лицензия — LGPLv3/GPLv2
по выбору, полный текст находится в архиве и в licenses/WinDivert/LICENSE.

Это исходники для просмотра и самостоятельной сборки. Для обычного запуска распаковывать
их не нужно. Бинарные файлы взяты без изменений из проверенного официального релиза
Flowseal 1.10.4. Исходники не собирались; соответствие исполняемых файлов конкретной сборке
проверено по происхождению релиза и встроенным версиям, а не воспроизводимой сборкой.

Точный дистрибутивный source package Cygwin 3.4.10-1 и его cygport-рецепт получить не удалось.
Полный upstream tag 3.4.10 получен, но исходные параметры/пакетный рецепт сборки именно
предоставленной DLL не подтверждены. Для изменений и пересборки см. README/configure
внутри исходных архивов. Ключи подписи оригинального драйвера в исходники не входят.

URL, git refs/commit и SHA-256 обоих архивов записаны в SOURCE-PROVENANCE.json.
