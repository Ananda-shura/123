ГОТОВАЯ ПАПКА ZAPRET 1.10.4 — ПРОФИЛЬ YOUTUBE

1. Распакуйте ВЕСЬ архив. Рекомендуемый путь: C:\Zapret-ready.
   Не запускайте файл внутри ZIP. Не копируйте поверх старой установки.
2. Откройте распакованную папку и дважды нажмите START.cmd.
3. В запросе Windows на права администратора нажмите «Да».
   Оставьте открывшееся окно работающим.

Скачивать исходный релиз отдельно, объединять папки или вводить команды не нужно.
Файлы bin уже внутри, их контрольные суммы проверяются до запуска.

Если старая копия Zapret уже работает, новый запуск сообщит об этом и остановится.
Закройте окно старой копии и снова нажмите START.cmd. Если старая копия работает службой,
временно остановите только свою службу zapret через «Службы» — не удаляйте её.
Чужие процессы/службы этот пакет не завершает. Если неясно, что запущено, пришлите текст ошибки.
При ошибке запуска её текст также сохраняется локально в logs\last-error.txt.

ДЛЯ ПРОВЕРКИ
Откройте YouTube: сайт, картинки, ролик 1080p 10 минут, перемотка.
Проверьте Steam: магазин, библиотеку, загрузку; CS2 — привычный сервер и показатели сети.
Запуск и воспроизведение на вашем компьютере ещё не проверены. Профиль не гарантирован
для любого провайдера. Он предназначен только для YouTube, не для обхода Discord.

ОСТАНОВКА И ОТКАТ
Нажмите Ctrl+C или закройте окно нового запуска. Вернитесь к сохранённой прежней папке.
Если временно остановили прежнюю службу, запустите её обратно через «Службы».
Исходная рабочая папка, DNS, брандмауэр, Defender и глобальные политики не изменяются.
Автозапуск не создаётся. После перезагрузки снова нажмите START.cmd.
WinDivert при работе может зарегистрировать/запустить собственный драйвер, как в оригинале.
Не отключайте защиту Windows ради запуска. Если Windows блокирует файл, сохраните текст сообщения.

ДЛЯ ИНТЕРЕСУЮЩИХСЯ
Оригинальные general*.bat и service.bat сохранены для сравнения. Для нового профиля они
не нужны: запускайте только START.cmd. Штатный service.bat умеет менять настройки и удалять
службы; его диагностика не предназначена для безопасного первичного сбора состояния.
Текст PowerShell-команды из START.cmd открыт для проверки в review\launcher-source.ps1.
START.cmd использует эту команду напрямую, не меняет ExecutionPolicy и ничего не скачивает.
Лицензии и соответствующие исходники зависимостей включены отдельно; их запускать не нужно.
