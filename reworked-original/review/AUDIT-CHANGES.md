# Доработка исходного релиза

Основа заново скачана с официального релиза 1.10.4 и сверена со всеми 59 файлами
пользовательского архива и Git-тегом. Источник и хэши записаны в SOURCE.json.
Изменены 24 оригинальных текстовых файла; все 27 файлов bin неизменны.
Это модифицированная конфигурация и логика BAT/PowerShell, не новый бинарный движок.

Подтверждённый пробел: общий QUIC-hostlist не включал список YouTube во всех 22 стратегиях.
Добавлен узкий YouTube-list, а не весь список Google с google.ru/шрифтами/Play.
Основной TLS-метод YouTube взят из успешного пользовательского прогона FAKE TLS AUTO ALT.
Повторы QUIC сохраняются по соответствующей исходной стратегии; их оптимальность не измерена.
Отдельное Telegram Web правило использует именно ранее проверенные параметры 681/Google-pattern,
а не похожий по названию общий multisplit исходного general.bat с другими параметрами.

Google/OpenAI/Telegram TCP теперь учитывают исходные и пользовательские доменные/IP-исключения.
Общие upstream-списки и исходные исключения сохранены; новые списки проверяются на границы доменов.
ALT5 намеренно отключён: фильтр по hostname не может корректно ограничить его исходный SYN-метод.
EXP сужен до распознаваемых Discord/STUN на его голосовых портах.
Game Filter и IPSet-заглушка сохраняют исходное выключенное состояние.

Service-логика проверена отдельно: обычный status не меняет глобальные TCP-параметры,
диагностика не ремонтирует систему удалением служб или очисткой кешей, ручное удаление
затрагивает только выбранную службу zapret после подтверждения. Общие драйверы/чужие процессы
не удаляются. Старый тест, изменяющий IPSet на ANY и убивающий все winws, заблокирован.
Исправления updater/переключателя IPSet защищают активный список от повреждения/пустого ANY.
Автоматическая проверка обновлений не входит в обычный запуск; версия не заменяется скрыто.
Генеральный валидатор IPSet сохраняет совместимость с точным устаревшим 6to4-префиксом
192.88.99.0/24 из проверенного официального каталога; его подпрефиксы и остальные
частные/документальные диапазоны не подпадают под это узкое исключение.
У исходных inline BAT остаётся лимит CMD в 8191 символ: инструкция требует короткий путь.
Проверка активных процессов предотвращает обнаруженный конфликт, но не заменяет mutex
для двух одновременных запусков; такой сценарий не объявляется поддерживаемым.

Уже установленные ограничения сохраняются: региональный отказ ChatGPT не устраняется DPI,
Telegram Web/TCP Established не доказывают MTProto. Работа через Happ подтверждена отдельно.
Новая сборка не объявляется универсальным исправлением всех сервисов/провайдеров.
