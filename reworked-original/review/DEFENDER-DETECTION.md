# Обнаружение Windows Security

27 октября 2026 года пользователь сообщил обнаружение `Trojan:Script/Wacatac.B!ml`
для скачанного `zapret-1.10.4-reworked.zip`. На втором экране статус — «Удален».
Windows указывает ZIP и URL скачивания; конкретный внутренний файл не указан.
Пользовательские пути, имя учётной записи и снимки экрана не публикуются.

SHA256 проверяемого опубликованного архива:
`2b2940f56218f8e3f02fdd8a463ba8265881d4c542fcd3f62dc214f68dba07d3`.

Повторно проверены CRC ZIP и SHA256 всех файлов по манифесту — расхождений нет.
Дополнительных EXE/DLL/SYS за пределами исходного bin в архиве нет.
Эти проверки подтверждают целостность и состав, но не доказывают безопасность.
Microsoft Defender и другая независимая антивирусная проверка в Linux не выполнены.
Конкретная причина обнаружения и статус false positive не установлены.

Рекомендация скачивать/запускать сборку отозвана. Защиту не следует отключать,
содержимое не следует восстанавливать/разрешать или добавлять в исключения ради запуска.
Архив сохранён неизменным для анализа; переупаковка ради исчезновения обнаружения
не является проверкой безопасности и не используется.
