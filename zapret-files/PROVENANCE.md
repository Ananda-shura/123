# Происхождение и контроль целостности

Исходный пользовательский ZIP и независимо скачанный официальный asset:
https://github.com/Flowseal/zapret-discord-youtube/releases/download/1.10.4/zapret-discord-youtube-1.10.4.zip

SHA-256 обоих архивов: `291af673bd0238506f9548e0e94ca0abf244000f4c9a06960544fb01c5f97b34`.
59 файлов совпали побайтно; дополнительные 4 записи ZIP — каталоги.
Тег 1.10.4 официального Git-репозитория: `176f56dc3f11ce5915c26abcdde903f93d835b64`.
Проверка выполнена через HTTPS с включённой проверкой сертификата.
GitHub API в этой среде вернул HTTP 403; метаданные digest API не получены.
Сравнение с официальным релизом подтверждает совпадение файлов, но не независимую криптографическую аттестацию сборки.
Authenticode и доверие к цепочке подписи на Windows здесь не проверялись.

ORIGINAL-SHA256.json содержит хэши всех 59 исходных файлов. Новый запуск проверяет все bin/*
перед исполнением. Это защита от случайной подмены относительно проверенного релиза,
не замена доверенной цифровой подписи: манифест тоже можно изменить.
Запуск из Linux не выполнялся; Windows EXE и драйвер не загружались.

Архив optimized содержит только дополнения и документацию, без бинарных файлов и драйверов.
Их повторная поставка с полным набором исходников/лицензий зависимостей отдельно не готовилась.
Используйте неизменённые оригинальные bin из проверенного ZIP 1.10.4.
