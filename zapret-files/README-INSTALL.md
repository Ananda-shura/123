# Установка дополнения для Zapret 1.10.4

Это кандидат для проверки на вашей Windows 11, а не подтверждённое исправление на вашем провайдере.
Архив `zapret-1.10.4-optimized.zip` — дополнение без EXE/DLL/SYS. В нём нет полного Zapret.
Существующие файлы не заменяются. Новый профиль предназначен только для YouTube.
Если нужен Discord, этот профиль не обеспечивает его обход: старые стратегии сохранены отдельно.

1. Сохраните ваш исходный ZIP 1.10.4 как резервную копию. Его SHA-256:
   `291af673bd0238506f9548e0e94ca0abf244000f4c9a06960544fb01c5f97b34`.
   Проверить можно в PowerShell: `Get-FileHash -Algorithm SHA256 'ПУТЬ-К-АРХИВУ.zip'`.
2. Распакуйте **исходный** ZIP в новую папку, например `C:\zapret-test`.
   В этой папке должны находиться `service.bat`, `bin`, `lists`, `utils`.
   Не работайте прямо внутри ZIP, не копируйте поверх используемой установки.
3. Распакуйте дополнение и скопируйте его содержимое в эту новую папку:
   `start-youtube.cmd` должен оказаться рядом с `service.bat`;
   новые файлы из `utils` и `lists` добавляются в одноимённые папки.
   Если Windows предлагает заменить уже существующие одноимённые файлы дополнения,
   используйте новую чистую папку, чтобы сохранить предыдущую копию.
4. Сначала откройте PowerShell в папке и соберите исходный отчёт:
   `powershell.exe -NoProfile -File .\utils\diagnose-readonly.ps1 -Label baseline`.
   Скрипт только читает настройки, выполняет DNS/HTTPS-запросы и пишет локальный отчёт.
   Никаких служб он не останавливает. Перед передачей отчёта проверьте приватные пути/адреса.
5. Закройте окно ранее запущенного вручную Zapret. Если Zapret работает службой,
   новый запуск откажется стартовать. Не удаляйте службу вслепую: сначала изучите отчёт.
   Остановка действующей службы — отдельное согласованное действие; в этом пакете она не автоматизирована.
   Для сравнения без Zapret повторите диагностику с `-Label without-zapret` после его ручной остановки.
   Метка baseline сама по себе не означает, что Zapret был выключен.
6. Откройте терминал **от имени администратора**, перейдите в новую папку и выполните
   ` .\start-youtube.cmd ` (без пробелов вокруг команды). Оставьте окно открытым.
   Запуск WinDivert необходим для работы Zapret; драйвер может зарегистрировать/запустить
   свою временную kernel-службу. Постоянная служба Zapret и автозапуск не создаются.
   Не продолжайте запуск, если администратор вашей системы запрещает загрузку этого драйвера.
7. Проверьте сайт YouTube, 1080p минимум 10 минут, перемотку и картинки.
   Потом Steam: магазин, сообщество, библиотеку и обычную загрузку обновления.
   В CS2 проверьте один и тот же сервер и показатели сети. Заполните `TEST-MATRIX.csv`.
   Соберите отчёт: `powershell.exe -NoProfile -File .\utils\diagnose-readonly.ps1 -Label optimized`.
8. Чтобы остановить профиль, нажмите Ctrl+C в его окне или закройте окно.
   Для отката вернитесь к ранее сохранённой папке/стратегии после проверки, что новый процесс завершился.
   Удалять службы, драйвер, DNS или сбрасывать сеть не нужно.

Если политика PowerShell блокирует скачанные файлы, сначала прочитайте сценарии.
При разрешении администратора снимите метку скачанного файла через его Свойства → Разблокировать
для этих проверенных локальных сценариев. Не меняйте глобальную ExecutionPolicy.
Организационные ограничения политики этот пакет не обходит.

До административного запуска можно отдельно проверить целостность без запуска EXE:
`powershell.exe -NoProfile -File .\utils\start-youtube.ps1 -ValidateFilesOnly`.
Пустой список доменов, отсутствующий файл или несовпадающий хэш останавливают проверку/запуск.

## Проверка QUIC

Откройте инструменты разработчика браузера → Сеть → добавьте столбец «Протокол».
На запросах YouTube/видео различайте `h3` (QUIC) и `h2` (TCP); curl-отчёт проверяет TCP,
но не доказывает работу HTTP/3 или видеосегментов. Ресурс `redirector.googlevideo.com`
сам по себе не проверяет воспроизведение.

Для дополнительного A/B запустите вместо обычного профиля:
`powershell.exe -NoProfile -File .\utils\start-youtube.ps1 -TcpOnly`.
Этот режим **не отключает QUIC**. Для осмысленного TCP-теста используйте отдельный
временный профиль браузера с выключенным QUIC, не меняя основной профиль и Windows.
Это необязательный диагностический опыт; обычный запуск обрабатывает TCP и UDP 443.
Не запускайте два режима одновременно.

## Сравнение и автозапуск

Сравните без Zapret, с прежней стратегией и с новым профилем: одинаковый браузер,
видео, качество, время теста и игровой сервер. Повторите раунды, учитывайте загрузку сети.
Запишите название исходной стратегии. Не используйте ALT5 как нейтральный тест для Steam:
он затрагивает широкий IPv4 TCP-трафик. Штатные Run Tests и Run Diagnostics не являются
диагностикой без изменений — см. AUDIT.md.

Автозапуск пока не настроен и после перезагрузки нужно запускать вручную.
Штатный Install Service не понимает PowerShell-профиль этого пакета; не выбирайте его для него.
После успешных локальных тестов можно отдельно согласовать постоянную службу/задачу
с точной командой и проверкой отката. Здесь такие команды не исполняются и не создаются.

## Ограничения

Этот профиль не меняет DNS, VPN, прокси, брандмауэр и антивирус. При ошибке DNS или конфликте
драйвера сначала нужна диагностика. Несовпадение SHA-256 останавливает запуск до исполнения EXE.
WinDivert всё равно перехватывает трафик порта 443 до выбора hostlist; нулевая задержка Steam
не гарантируется. Игровые порты 27015 и подобные новый фильтр не включает, но общие системные
конфликты драйверов/античита могут оставаться. Скрытие WinDivert и обход античита не применяются.
